# Speaker Switching Demo

## Usage

1. Edit `config.yaml` and prepare your own data

2. Run `instruct_prompt.py`

3. Run `infer.py`

If you need to train your own model, you can use `instruct_prompt.py` to generate the data and then train with the ms-swift tool.

## Quick Start

```bash
pip install -r requirements.txt
bash main.sh
